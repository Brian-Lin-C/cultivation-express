# 我在修仙界送外卖

- **中文名**：我在修仙界送外卖
- **英文名**：Cultivation Express
- **一句话简介**：穿越修仙界，送外卖送到证道成仙。
- **标签**：文字游戏 · 修仙 · 外卖 · 放置挂机 · 经营养成 · 随机事件 · 多结局 · 单机 · 手机可玩
- **署名**：LC

## 这是什么

一款纯文字浏览器小游戏。你是一个被天雷劈进修仙界的现代外卖小哥，为了糊口（和攒灵石买回家符）重操旧业：接单、赶路、应对途中各种幺蛾子、拿好评、升级坐骑与功法——从一双腿跑到挪移玉符，从坊市送到魔域。

## 玩法

- **接单配送**：每次 3 张订单符任选，报酬、时限、区域各不相同；途中随机触发事件，选择影响餐品完整度与耗时
- **评价系统**：按完整度与时效结算 1–5 星；好评攒功德，三连差评遭天谴⚡
- **经营养成**：5 档坐骑、3 条外卖箱强化线（灵石）、5 门功法（功德）
- **境界晋升**：送餐攒经验，从「见习骑手」一路升到「配送圣人」，解锁更远更危险（也更赚钱）的区域
- **雇佣骑手（v1.1）**：灵石雇佣骑手小弟自动送单，配调度令牌扩展自动配送区域；**离线也会跑单**（8 小时封顶），回来弹结算单
- **灵蝶机缘（v1.1）**：随机飘过的灵蝶限时点击，得灵石/功德/神速 buff/平安符
- **成就即战力（v1.1）**：每个成就永久 +2% 报酬，轮回保留
- **宿敌榜（v1.1）**：与蓝袍宗·燕十三实时比拼骑手积分，日志常有他的传闻，登顶有专属成就
- **熟客系统（v1.2）**：同一客人 3 次好评变熟客，❤️ 标识、报酬 +30%、必给小费
- **渡劫仪式（v1.2）**：境界突破时弹出渡劫抉择——硬抗赌大奖 / 金钟护体稳妥 / 孝敬雷神买 buff
- **轮回天赋树（v1.2）**：轮回结算「天道印记」，兑换 6 种跨世永久天赋（开局速度/灵石/自带骑手/天谴免疫/订单栏位/熟客保留）
- **多结果事件（v2.0）**：每个事件选项藏 2~4 种加权结果（正面/中性/负面），气运与灵眸等级动态偏移概率——同一个选择，每次都可能是不同的故事
- **因果链（v2.0）**：请劫修吃饭 → 他改邪归正后拦路报恩；喂过仙鹤 → 日后为你引路；呵斥魔修结仇 → 魔域遭到伏击……你的选择会记住你
- **气运 & 道心（v2.0）**：新增双资源。气运偏移随机事件好坏；道心是灵眸绕路的「燃料」，好评/打坐回复，差评扣减
- **灵眸改版（v2.0）**：事件绕路不再无代价——消耗道心且有成功率（85% 起步，连续使用递减，最低 20%），失败遭反噬
- **角色命名（v2.0）**：开局自定义道号，显示于顶栏、骑手榜与生涯；设置页可随时改名
- **境界试炼（v2.0）**：到达 4/6/8 级门槛需完成专属试炼单（拜山帖/秘境信标/投名状）方可突破，好评送达才算过关
- **选项情报（v2.0）**：每个选项附灰字后果提示；部分选项需特定境界才解锁
- **配送史册（v2.0）**：图鉴页记录你的关键抉择与因果，最近 12 条随时回顾
- **时空彩蛋（v2.0）**：0.6% 概率触发「时空裂隙」——收到来自现代世界的神秘订单
- **实时倒计时（v2.0）**：订单倒计时每秒刷新，抉择弹窗时显示暂停态
- **门派悬赏（v2.1）**：3 张滚动任务（配送数/五星/远征/完美送达/事件化险/连击/小费/打坐），完成领奖，全清另有全勤奖
- **五星连击（v2.1）**：连续五星好评叠加报酬加成（每连 +5%，封顶 25%），中评/差评清零——手感越烫赚得越多
- **事件冷却（v2.1）**：最近出现的事件自动降权，因果事件触发一次即清除，不再连续重复
- **事件库扩充（v2.1）**：事件 20 → 30 个（迷路同行/出餐错误/飞剑飙车党/乞修/封路/以物易物/碰瓷/灵兽拦路 + 乞修/灵兽报恩因果链）
- **移动端布局（v2.1）**：App 式视口（100dvh），顶栏/页签/日志常驻可见，内容区内部滚动，不再被浏览器工具栏遮挡
- **buff 实时条（v2.1）**：神速/平安符等状态独立常驻显示，每秒刷新倒计时
- **放置要素**：空闲时可打坐缓慢积累功德与道心
- **多结局轮回**：还乡 / 外卖帝国 / 功德飞升 / 隐藏结局，共 4 种；结局后进入轮回，保留成就并获得速度传承
- **成就图鉴**：20 个成就 + 结局收集

## 运行方式

纯静态目录，无需任何构建与后端：

- 本地：直接双击 `index.html` 即可游玩
- 部署：把整个目录放到站点任意子路径下（如 `/toys/cultivation-express/`），用 `<iframe src="/toys/cultivation-express/">` 嵌入即可
- 在线试玩（GitHub Pages）：https://brian-lin-c.github.io/cultivation-express/

## 技术说明

- 零依赖、零外链资源（无 CDN / 无外部字体 / 无图片 / 无音频）
- 所有引用均为 `./` 相对路径
- 存档存于浏览器 localStorage，键名前缀 `cultexpress_`，支持导出/导入存档码
- 响应式布局，触屏可玩，适配任意容器宽度

## 目录结构

```
cultivation-express/
├── index.html      # 入口
├── css/style.css   # 墨卷风 UI
├── js/data.js      # 数据表（区域/坐骑/功法/事件库·多结果因果链/试炼/骑手/灵蝶/宿敌/成就/结局）
└── js/game.js      # 引擎（配送循环/评价/事件摇号/因果链/自动化/离线结算/商店/存档）
```

加内容（新事件、新餐品、新客户、新结局）只需改 `js/data.js`，不用动引擎。
