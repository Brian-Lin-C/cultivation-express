# 我在修仙界送外卖

- **中文名**：我在修仙界送外卖
- **英文名**：Cultivation Express
- **一句话简介**：穿越修仙界，送外卖送到证道成仙。
- **标签**：文字游戏 · 修仙 · 外卖 · 经营养成 · 随机事件 · 多结局 · 单机 · 手机可玩
- **署名**：LC

## 这是什么

一款纯文字浏览器小游戏。你是一个被天雷劈进修仙界的现代外卖小哥，为了糊口（和攒灵石买回家符）重操旧业：接单、赶路、应对途中各种幺蛾子、拿好评、升级坐骑与功法——从一双腿跑到挪移玉符，从坊市送到魔域。

## 玩法

- **接单配送**：每次 3 张订单符任选，报酬、时限、区域各不相同；途中随机触发事件，选择影响餐品完整度与耗时
- **评价系统**：按完整度与时效结算 1–5 星；好评攒功德，三连差评遭天谴⚡
- **经营养成**：5 档坐骑、3 条外卖箱强化线（灵石）、5 门功法（功德）
- **境界晋升**：送餐攒经验，从「见习骑手」一路升到「配送圣人」，解锁更远更危险（也更赚钱）的区域
- **放置要素**：空闲时可打坐缓慢积累功德
- **多结局轮回**：还乡 / 外卖帝国 / 功德飞升 / 隐藏结局，共 4 种；结局后进入轮回，保留成就并获得速度传承
- **成就图鉴**：13 个成就 + 结局收集

## 运行方式

纯静态目录，无需任何构建与后端：

- 本地：直接双击 `index.html` 即可游玩
- 部署：把整个目录放到站点任意子路径下（如 `/toys/cultivation-express/`），用 `<iframe src="/toys/cultivation-express/">` 嵌入即可

## 技术说明

- 零依赖、零外链资源（无 CDN / 无外部字体 / 无图片 / 无音频）
- 所有引用均为 `./` 相对路径
- 存档存于浏览器 localStorage，键名前缀 `cultexpress_`，支持导出/导入存档码
- 响应式布局，触屏可玩，适配任意容器宽度

## 目录结构

```
cultivation-express/
├── index.html      # 入口
├── css/style.css   # 墨卷风 UI
├── js/data.js      # 数据表（区域/坐骑/功法/事件库/成就/结局）
└── js/game.js      # 引擎（配送循环/评价/商店/存档）
```

加内容（新事件、新餐品、新客户、新结局）只需改 `js/data.js`，不用动引擎。
